# Disease Prediction System | ML Portfolio Project

## Overview
End-to-end Machine Learning project predicting Diabetes and Heart Disease risk using clinical datasets.

## Projects
1. diabetes_prediction.ipynb - Diabetes prediction using Pima Indians Dataset, Accuracy ~78%
2. heart_attack_prediction.ipynb - Heart disease prediction using Heart UCI dataset

## Tech Stack
Python, Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn, Jupyter
